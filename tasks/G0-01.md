## Done/FAIL 判定

| 检查点 | 正例 / 反例要求 |
| --- | --- |
| Event ID / communicator | 真实事件可稳定关联 Rank、GPU UUID 和 communicator，若缺失明确为 UNKNOWN |

| Rank 可用性 | 有独立证据区别晚到、等待与通信慢，或者明确说明不可区分 |
| 安全性 | 不暂停训练，不添加 in-band collective、不在热路径执行阻塞 GPU 同步 |
| 开销 | 提供实际 p50/p95 迭代耗时与采样开销，未知不填 PASS |
